# XREAL Space

App tự viết cho kính XREAL Air 2 (đời cũ, hãng hết hỗ trợ): màn hình ảo đứng yên trong không gian, điều khiển bằng điện thoại, đầu và giọng nói.
Dùng để xem phim, làm việc và tiện ích khi di chuyển.

| Thư mục | Nội dung |
| --- | --- |
| [`android/`](android/) | App Android (Kotlin) — bản chính, chạy trên điện thoại / XREAL Beam / Beam Pro |
| [`pc/`](pc/) | Prototype PC (Python): 3 màn hình desktop trên kính, HUD, bản đồ |
| [`pythontest/`](pythontest/) | xr-air-lab: thư viện Python đọc IMU kính, tài liệu giao thức USB, test |
| [`docs/WIKI.md`](docs/WIKI.md) | **Wiki**: tính năng, hướng dẫn, kiến trúc, giới hạn, nợ kỹ thuật, checklist |

**Lấy APK:** tab *Actions* → workflow `android-apk` → lần chạy mới nhất → *Artifacts*.

Repo private. Tên "XREAL" là thương hiệu của XREAL; dự án không liên quan tới hãng.
